Your image never leaves the device — all processing happens locally.

Works best on a genuinely low-res or compressed source. If an image was already blown up with simple resizing before you got it, that detail is gone for good — no upscaler, ours or otherwise, can recover information a smaller image never captured.

Tiles keep memory bounded. Smaller tiles are safer on phones; the overlap is cropped away after inference so seams stay invisible.

original upscaled

The upscaled image is painted tile by tile as it is produced. Drag the divider to compare — and switch to 100% above the preview, since "Fit" scales the added detail back down along with the image.

Models are Real‑ESRGAN (BSD‑3‑Clause) and Swin2SR (Apache‑2.0), exported to ONNX; inference by ONNX Runtime Web (MIT). No image data is uploaded, and after the first run the app works offline.
